# net67 0.23.67

- Подбор стратегий умеет HTTP и QUIC, а не только HTTPS. Протокол выбирается по контрольным измерениям, у каждого свой профиль и своя история. Ложные успехи отсеиваются проверкой объёма ответа и нескольких адресов.
- После «Применить» сайт проверяется через пользовательский пресет, а затем открывается в настоящем браузере (Edge или Chrome без окна). Если браузер сайт не открыл, программа предупредит и назовёт причину.
- BlockCheck и подбор проверяют сайты так же, как это делает Chrome. Проверки больше не открывают десяток соединений разом: по ним фильтр узнавал проверку, и она видела не то, что увидит браузер.
- BlockCheck по умолчанию проверяет только сайты и работает быстро. Шумные проверки перенесены в режим «Глубокая диагностика». Разбор причины показывается только у сайтов, которые не открылись.
- «Проверка домена» сначала показывает то же, что увидит браузер, а подробный разбор идёт следом.
- Telegram Proxy подключается быстрее в сетях с заблокированным релеем. Картинки и видео больше не пропадают на несколько секунд при смене пути. Обновлены адреса входа дата-центров, DC203 работает через Cloudflare.
- В редакторе hosts профиль net67 DNS доступен и для «Остальных сервисов».
- Окно быстрее открывается из трея и не зависает при возврате после долгой работы в фоне.
- Исправлено: на компьютерах, где программа лежит в папке с русскими буквами, проверки сайтов считали, что интернета нет.
- Исправлено: падение при открытии прошлой проверки в BlockCheck.
- Исправлено: кнопка «Назад» в обучающем туре пропускала шаги раздела «Инструменты».
