# net67 0.22.67

- Обход показывает состояние «включён» после запуска движка. Проверка доступности сайтов выполняется отдельно; её ошибка не выключает обход.
- Обновлён BlockCheck: результаты появляются постепенно, карточки открывают измерения и подробности. Добавлены подробный режим, история и вкладка «DNS-серверы».
- Исправлен «Экспресс»: он проверяет максимум пять стратегий. Дополнительные варианты в других режимах также входят в выбранный лимит.
- Исправлены падение BlockCheck при чтении кэша, создание журнала подбора и ошибка карточки при открытых подробностях.
- «Обновить адреса» в hosts проверяет адреса в фоне, сохраняет выбранные профили и ручные записи. При ошибке записи прежний набор восстанавливается.
- net67 DNS добавлен в «Настройку DNS» → «Малоизвестные» с собственной иконкой. Сервер разрешает обычные сайты, сохраняет маршруты нейросетей и фильтрует рекламные домены через AdGuard DNS. Поддерживаются IPv6 и DNSSEC; обычный DNS не шифруется. Фон плиток соответствует общей палитре приложения.
- Исправлены завершение фоновых задач и сохранение настроек при обновлении. Обновлены статьи вики.
- Сборка больше не подхватывает несовместимые системные библиотеки из сторонних инструментов на компьютере разработчика.
