# net67 0.24.67

- Обновлён движок обхода: новая сборка работает без дополнительной библиотеки Cygwin. Обход останавливается мягко — движок завершается сам и сразу освобождает сеть. После правки списка сайтов в профиле движок перечитывает его без перезапуска.
- Добавлены семь встроенных пресетов: white sni (circular), shadow probes (circular), slow split, slow disorder, tls records, fake close и protocol mask (stun). Пресет white sni запоминает, какой способ сработал для каждого сервера, и в следующий раз пробует его первым.
- В редакторе hosts появился выключатель «Умная проверка адресов». По умолчанию он выключен. Включённая проверка раз в шесть часов и после включения сервиса проверяет адреса и ставит первым рабочий. Она меняет только записи net67 и ждёт, пока идут проверки, запущенные вручную.
- Окно «Доступно обновление» больше не всплывает, пока программа свёрнута в трей: оно появится, когда окно программы откроют.
- В разделе «О программе» появилась кнопка «Что нового» — список изменений можно открыть в любой момент.
- Окно быстрее открывается из трея после долгой работы в фоне.
- Исправлено: если при первой настройке снять все галочки в вопросе про hosts, программа больше не включает сервисы сама при следующем запуске.
- Исправлено: выход из программы больше не задерживается на две секунды.
- В журнале больше нет ложных предупреждений о том, что страницы загружались по несколько минут.
