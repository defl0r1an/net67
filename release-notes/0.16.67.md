**Что нового**

- **Нейросети снова открываются.** 8 октября сервер XBOX DNS перестал
  пропускать ChatGPT, Claude, Gemini, Grok и Copilot, и у всех на
  настройках по умолчанию они не открывались. Теперь нейросети по
  умолчанию идут через GeoHide — по проверке он открывает их все. Если у
  вас был выбран XBOX DNS, программа сама подставит рабочий вариант, ничего
  делать не нужно.
- **Адреса в редакторе hosts обновлены.** Сервисы Comss DNS, AstraCat,
  GeoHide и DNS-AI сменили часть адресов — каталог пересчитан заново.
  Неработающие XBOX DNS (old) и Malw DNS убраны.
- **Настройка DNS.** Из раздела «Для ИИ» убраны XBOX DNS и dns.malw.link:
  первый больше не открывает нейросети, второй не отвечает. Если они были
  прописаны у сетевого адаптера, программа при запуске сама заменит их на
  GeoHide.
- **Telegram.** В hosts прописываются ещё два адреса Telegram.
- **Установщик.** Галочка «Запустить net67» в конце установки снова
  открывает программу — раньше та сразу закрывалась.
