# net67 0.20.67

- «Проверка домена» в BlockCheck: ответы DNS, отклик адреса, сведения о сети и имена из сертификата. Найденный адрес можно добавить в hosts.
- Ручные записи с пометкой `net67:manual` сохраняются при переключении профилей hosts.
- Режим «Экспресс · 5» проверяет до пяти стратегий и останавливается на первой, прошедшей три проверки.
- Трей показывает отклик проверочных адресов. При недоступном ICMP используются TCP-проверки; отсутствие ответа не объявляется отсутствием интернета.
- В hosts добавлена временная подсветка нескольких плиток; проверка профилей отмечает рекомендацию, сохраняя выбранный профиль.
- Перед запуском обхода проверяется состояние драйвера. При обнаруженной проблеме программа пробует восстановление.
- Вкладка Antigravity получила общую кнопку включения и отключения с выбором, сохранять ли профили ИИ в hosts.
- Обновлены индикация запуска и остановки и значок проверки обновлений. Telegram остаётся ненастроенным.
- Xray выбирает локальный порт, доступный для TCP и UDP, если прежний порт занят или запрещён Windows.
