# net67 0.27.67

- При обрыве скачивания обновлятор делает до трёх попыток. Если сервер поддерживает докачку, уже полученные части сохраняются, в том числе для кнопки «Повторить». Перед установкой проверяется целостность файла.
- Прогресс загрузки одинаковый в окне и на странице обновлений. Когда сервер перестаёт присылать данные, появляется «Ждём ответа сервера…», а устаревшие скорость и оставшееся время скрываются.
- В пресеты и списки сервисов добавлены Matrix и SimpleX, включая отдельный вариант SimpleX по IP. Ручное размещение плиток и оценки сохраняются.
- В Default v1 обновлены стратегии Signal и YouTube. В игровом варианте служебные домены Google используют ту же стратегию, что и сайт YouTube.
- Диагностика YouTube точнее различает недоступность адреса видеосервера и сбой соединения с именем сайта.
- Исправлено падение при повторном открытии меню из трея: его пункты сохраняются, а временные обработчики удаляются после закрытия.
- Вики приведена к текущему интерфейсу: шифрованный DNS на Windows 10, главная карточка, экскурсии по главам, обновления, парная проверка BlockCheck и ссылка на netgram.
