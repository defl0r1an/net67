# Словарь терминов

### DPI

Deep Packet Inspection, глубокий разбор пакетов. Оборудование, которое читает содержимое сетевого трафика, а не только адреса отправителя и получателя. Именно оно опознаёт, к какому сайту идёт соединение.

### ТСПУ

Технические средства противодействия угрозам. Российское название оборудования DPI, устанавливаемого у операторов связи централизованно.

### SNI

Server Name Indication, поле в начале зашифрованного соединения с именем сайта. Передаётся открытым текстом, потому что без него сервер не поймёт, чей сертификат предъявлять. Отсюда и уязвимость: имя видно всем на пути. См. [[how-it-works|Как работает обход]].

### Стратегия

Один приём обмана оборудования: разрезать приветствие, отправить пустышку, испортить контрольную сумму. См. [[bypass|Обход и пресеты]].

### Профиль

Стратегия, применённая к определённому набору сайтов.

### Пресет

Готовый набор профилей. То, что выбирается в программе.

### Хостлист

Список доменов в текстовом файле, к которым применяется стратегия. См. [[lists|Списки сайтов]].

### winws2

Движок обхода — программа (`winws2.exe`), которая и правит сетевые пакеты. net67 её запускает и передаёт ей аргументы, собранные из пресета. См. [[about|О программе]].

### WinDivert

Драйвер, позволяющий перехватывать и изменять сетевые пакеты в Windows. То самое место, ради которого нужны права администратора.

### DNS

Служба перевода имён сайтов в адреса. Её подмена — отдельный вид блокировки, см. [[dns|Настройка DNS]].

### DoH

DNS-over-HTTPS, шифрование запросов к DNS через HTTPS. В net67 используется встроенная поддержка Windows 11 или локальная служба на Windows 10. Доступность самого сервера шифрование не гарантирует, см. [[dns#Шифрование запросов|Настройка DNS]].

### DNSCrypt и ODoH

Режимы шифрованного DNS из группы «Шифрованные». Анонимный DNSCrypt и ODoH добавляют посредника, отделяющего ваш адрес от DNS-сервера. Выбор режима и ограничения — в [[dns#Шифрование запросов|Настройке DNS]].

### hosts

Системный файл Windows, задающий адреса для отдельных имён в обход DNS. Используется [[hosts|редактором hosts]] и [[max|блокировкой MAX]].

### DNS-профиль

Набор адресов одного сервиса-посредника в [[hosts#DNS-профили|редакторе hosts]]: XBOX DNS, Comss DNS и другие. Через посредника открываются сервисы, закрытые для России.

### Xray

Ядро для подключения по ссылке. Поднимает локальный прокси, через который идёт трафик. См. [[vpn|VPN по ссылке]].

### AmneziaWG

Вариант WireGuard с маскировкой трафика. Создаёт настоящий сетевой туннель.

### VLESS, VMess, Trojan, Shadowsocks

Протоколы подключения к серверам, поддерживаемые ядром Xray. Ссылка на сервер начинается с названия протокола: `vless://`, `vmess://` и так далее.

### Подписка

Ссылка, по которой отдаётся список серверов разом, а не один. Удобна тем, что серверы обновляются на стороне поставщика.

### MTProxy

Прокси, придуманный специально для Telegram. См. [[telegram|Telegram Proxy]].
