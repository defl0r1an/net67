# Редактор hosts

Раздел «Инструменты → Редактор hosts» решает задачу, отличную от [[bypass|обхода]], и путать их не стоит.

## Зачем он нужен

Обход помогает, когда сайт блокирует провайдер. Часть сервисов закрывается иначе: смотрит, из какой страны пришёл запрос, и не пускает. Так устроены ChatGPT, Claude, Gemini и многие другие. Обход здесь бесполезен — он прячет имя сайта от провайдера, но не меняет адрес отправителя.

Редактор hosts заходит с другой стороны. Он прописывает сервису адрес сервера-посредника, который пускает всех, и браузер идёт туда напрямую, минуя обычный перевод имени в адрес. Посредник пересылает соединение настоящему сайту. Шифрование при этом сквозное: посредник видит только имя сайта, но не содержимое.

Работает не везде: сервис может проверять адрес и дальше, уже внутри. Но для многих этого хватает.

## Как пользоваться

Страница — это сетка плиток, по плитке на сервис. Щелчок по плитке включает сервис, и адреса **сразу** записываются в системный файл `hosts`. Кнопки «Применить» нет.

После записи нужно перезапустить браузер: он помнит прежние адреса.

Сверху — поиск по названию сервиса и сводка: сколько сервисов включено и сколько строк net67 держит в файле.

Сервисы разложены на три группы:

| Группа | Что это | Как открывается |
| --- | --- | --- |
| **Напрямую** | YouTube, Discord, Instagram и другие | адрес прописывается как есть, посредник не нужен |
| **ИИ-сервисы** | ChatGPT, Claude, Gemini, Grok, Copilot, Cursor, Groq, Google Antigravity и другие | закрыты для России сами, нужен DNS-профиль |
| **Остальные сервисы** | Spotify, JetBrains, Notion, Twitch, IKEA, LEGO, Crunchyroll и другие | через DNS-профиль |

У каждого сервиса на плитке свой логотип. У выключенного сервиса он серый — так включённые видно в сетке издалека.

Новые сервисы появляются выключенными: обновление программы само ничего не дописывает в ваш файл `hosts`.

> [!note] Google Antigravity и Gemini
> Программа Antigravity работает через тот же адрес Google, что и Gemini (`daily-cloudcode-pa.googleapis.com`), поэтому он есть у обоих сервисов. Если для них выбраны разные профили, этот адрес пойдёт через профиль Antigravity.

## DNS-профили

У сервисов из второй и третьей группы на плитке стоит ряд значков. Каждый значок — профиль: набор адресов одного сервиса-посредника. Полное имя профиля видно в подсказке при наведении.

| Профиль | Что стоит за ним |
| --- | --- |
| GeoHide | geohide.ru |
| DNS-AI | dns-ai.ru |
| Comss DNS | dns.comss.one |
| AstraCat | dns.astracat.network |
| Zapret DNS | dns.zapret.moe, сервер 83.217.211.149 |
| XBOX DNS | xbox-dns.ru; с 8 октября 2026 нейросети через него не открываются |

Профили работают по-разному: один быстрее, другой стабильнее, третий может перестать отвечать в любой момент. У разных сервисов набор профилей разный — посредник обслуживает только сайты из своего списка. Профиль показывается у сервиса, только если у профиля есть адрес для каждого имени этого сервиса: наполовину прописанный сервис всё равно не откроется.

Адреса профилей программа берёт из своего каталога, а каталог пересчитывается замером с российской линии. У каждого профиля первым стоит адрес, который отвечал при замере: Windows и браузер идут на первую строку `hosts`.

Если сервис не открывается, стоит щёлкнуть по другому значку на его плитке. Цифры на клавиатуре выбирают профиль по порядку.

### Кнопка проверки

Перебирать значки наугад не нужно. Сразу за названием сервиса стоит круглая кнопка с полосками сигнала. По щелчку программа сама обходит все профили этого сервиса: соединяется с адресом профиля, проверяет сертификат сайта и запрашивает страницу. Занимает это около десяти секунд, справа от названия идёт счётчик.

Проверяется именно тот адрес профиля, на который пойдёт браузер, — первый. Запасные адреса ниже браузер пробует только после долгого ожидания первого, и засчитывать их было бы нечестно: проверка говорила бы «открылось», а сайт в браузере висел бы.

Когда проверка закончилась, на значках профилей появляются отметки:

- зелёная точка — сайт через этот профиль открылся;
- золотое кольцо и молния — лучший профиль: открыл больше всего, при равенстве самый быстрый. Его имя с молнией встаёт и справа от названия сервиса;
- красная точка — не открылся. Причина видна в подсказке при наведении: адрес не отвечает, соединение обрывается, адрес отдаёт чужой сертификат, сайт отвечает «недоступно в вашей стране» или отказывает (ответ 403).

Ответ 403 — отказ: так, например, отвечает ChatGPT на соединение из России. Исключение — проверка Cloudflare «вы человек?»: она тоже приходит с кодом 403, но в браузере обычно проходит сама, и такой профиль считается открывшимся.

Выбрать лучший — щёлкнуть по его значку с молнией. Сама кнопка выбор не меняет и в `hosts` ничего не пишет: после проверки щелчок по ней запускает проверку заново. Отметки остаются на плитке, какой бы профиль ни был выбран.

С клавиатуры кнопку заменяет Shift+Enter на выбранной плитке.

> [!note] Проверка показывает сегодняшний день
> Результат зависит от провайдера и от того, включён ли обход. Профиль, который не открылся при выключенном обходе, при включённом может заработать, и наоборот.

Кнопка **«DNS для всех»** ставит один профиль сразу всем сервисам, у которых он есть. Потом любой можно поменять отдельно.

> [!note] Какой профиль стоит по умолчанию
> GeoHide: адреса у него есть для большего числа сервисов, чем у любого другого профиля, и по замеру 9 октября 2026 он открывал все нейросети каталога. Если у сервиса GeoHide нет, берётся следующий по порядку: DNS-AI, Comss DNS, AstraCat, Zapret DNS, XBOX DNS. Тот же порядок выручает, когда выбранный вами профиль убран из каталога: сервис получает следующий, а ваш выбор в настройках остаётся как был.

## Как устроена запись

Строки net67 лежат в файле отдельным блоком, помеченным маркерами. Выключение сервиса убирает его строки из блока. Чужие строки не затрагиваются: если в файл что-то добавлял пользователь или другая программа, оно останется на месте.

> [!note] Файл hosts один на всю систему
> Его правят многие программы, и разметка блока маркерами — не украшение. По ним программа находит своё и не сносит лишнего.

Кнопка **«Файл hosts»** показывает весь файл целиком, с раскраской строк по владельцам: что написал net67, что — блокировка MAX, что было до них. Файл там же можно править и сохранить. Блок net67 при этом перепишется при следующем переключении сервиса.

## Telegram

Плитки Telegram здесь нет. Записи для Telegram Web пишет раздел [[telegram|Telegram Proxy]]: у файла hosts должен быть один хозяин для каждой группы строк, иначе два раздела затирали бы записи друг друга.

## Права и защита файла

Файл `hosts` системный, и Windows не даёт править его обычному пользователю. Программа и так работает с правами администратора, поэтому отдельных запросов не будет.

Бывает, что запись всё равно не проходит:

- **Файл защищён от записи** — стоит отметка «только чтение». Программа сама её не снимает: её мог поставить человек намеренно.
- **Нет доступа** — чаще всего запись блокирует антивирус.

В обоих случаях на странице появляется пояснение и кнопка **«Снять защиту и восстановить права»**.

## Если что-то сломалось

Симптом узнаваемый: сервис перестал открываться вовсе, хотя раньше работал. Значит, в `hosts` осталась запись на сервер, который больше не отвечает.

Сначала — [[#Кнопка проверки|кнопка проверки]] на плитке: она покажет, какой профиль сейчас рабочий. Ни один не открылся — выключить плитку: записи сервиса уйдут из файла, и браузер пойдёт обычным путём.

## Соседний блок

Тот же файл использует [[max|блокировка MAX]] — она пишет свой блок, со своей меткой. Разделы независимы: выключение одного не трогает записи другого.
