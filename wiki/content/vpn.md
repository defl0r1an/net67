# VPN по ссылке

> [!note] Изменения в dev после 0.28.67
> Новая компоновка, поиск, проверка групп, полный набор флагов и отмена подключения доступны в ветке dev.

Раздел «Инструменты → VPN» нужен там, где [[bypass|обход]] не справляется: когда доступ закрывает сам сервис по стране, а не провайдер по имени сайта.

Вкладки две, и устроены они по-разному.

## Вкладка «VPN» — подключение по ссылке

Работает через ядро Xray. Принимает ссылку на один сервер (`vless://`, `vmess://`, `trojan://`, `ss://`) либо адрес подписки — из подписки разом берутся все серверы, обычно два-три десятка.

Нажмите **«Добавить»**, вставьте ссылку в небольшом окне и подтвердите кнопкой **«Добавить»**. Подписка, ссылка, ключ `vpn://` или текст `.conf` распознаются по содержимому. Для файла есть **«Выбрать файл»**. Ключи и серверы программа не выдаёт.

Выберите сервер в списке и нажмите большую круглую кнопку справа. **«Подключить»** во время запуска становится **«Отменить»**, после запуска — **«Отключить»**. Отмена дожидается текущего системного шага и снимает создаваемое соединение. При работающем Xray выбор другой строки сервера переключает на неё.

Кнопка **«Пинг»** справа проверяет сервер, показанный рядом с ней. Для Xray она отправляет HTTPS-запрос с проверкой сертификата. Для проверки другого сервера запускается отдельный временный экземпляр ядра. Задержка показывает время до ответа проверочного сайта.

Нажмите **«Пинг всех»** в заголовке группы, чтобы проверить все её серверы, включая скрытые поиском. Результаты появляются справа в строках по мере готовности. Кнопка **«Стоп»** показывает ход проверки и позволяет остановить очередь. Вид, время и подробности замера доступны в подсказке строки.

## Поиск и флаги

Поиск понимает названия серверов, адреса и русские и английские названия стран. Поиск и сворачивание группы сохраняют выбор. Серверы подписок объединены в группы. **«Обновить»** перечитывает подписки без повторного добавления ссылки.

Флаги — картинки полного набора стран и территорий, включая Кипр и Антарктиду. Страна определяется по названию, двухбуквенному коду или эмодзи в профиле; флаг не подтверждает физическое расположение сервера. Если страну определить не удалось, показывается глобус.

> [!note] Как это устроено внутри
> Ядро Xray поднимает локальный прокси и само по себе трафик никуда не заворачивает. Чтобы система пошла через него, программа прописывает этот прокси в настройки Windows и возвращает их обратно при отключении.
>
> Программы, которые учитывают системный прокси, могут использовать этот маршрут. Приложения с собственными сетевыми настройками могут идти напрямую.

Переключатель **«Весь компьютер»** задаёт охват Xray. Когда он выключен, используется прокси приложений Windows. Для включённого режима нужны tun2socks и права администратора. Изменение применяется при следующем подключении; ожидающее изменение отмечается под переключателем. Если вместо туннеля действует прокси приложений или только локальный прокси, программа показывает фактический охват.

## Вкладка «Amnezia» — файлы конфигурации

Работает с профилями AmneziaWG: ключ вида `vpn://...` или файл `.conf` с секциями `[Interface]` и `[Peer]`.

Программа создаёт сетевой адаптер и службу Windows. Охват задают маршруты конфигурации, в частности `AllowedIPs`. Наличие адаптера ещё не подтверждает обмен с сервером. Проверка Amnezia использует сведения о рукопожатии и сетевые пробы; это не подтверждение HTTPS через выбранный маршрут.

## Чем отличаются вкладки

| | VPN (Xray) | Amnezia (AmneziaWG) |
| --- | --- | --- |
| Что принимает | ссылку или подписку | ключ или файл `.conf` |
| Как направляет трафик | прокси приложений или режим «Весь компьютер» | сетевой адаптер |
| Программы со своими сетевыми настройками | для них может потребоваться туннельный режим | используют маршруты туннеля |
| Переключение сервера | на лету | переподключением |

## Кнопка сохранения

Подпись у неё меняется, и не для красоты — сохраняется разное.

У профиля AmneziaWG / WireGuard это «Сохранить как .conf»: получается конфигурация для клиента, поддерживающего протокол и параметры вашего профиля.

У сервера из ссылки такого файла не существует — там нет ни приватного ключа, ни адреса в туннеле, всё это задаёт ядро Xray само. Поэтому подпись другая, «Сохранить настройки сервера», и сохраняется настройка ядра в формате JSON.

## Если не подключается

Нажмите «Пинг» справа и посмотрите сообщение рядом с кнопкой. Если проверочный запрос не прошёл, попробуйте другой сервер.

Если после аварийного завершения программы пропал интернет, проверьте прокси Windows. При открытии вкладки VPN net67 проверяет собственные оставшиеся настройки. Вручную прокси отключается в «Параметры → Сеть и Интернет → Прокси».

**«Удалить»** убирает выбранный профиль из локального списка. Обновление подписки может вернуть сервер, который по-прежнему есть у её владельца. Выгруженные конфигурации могут содержать ключи доступа — не публикуйте их вместе с журналом.
