# Устройство пресета

Пресет — обычный текстовый файл `.txt`. Каждая строка в нём — одна настройка движка `winws2`, и запускается ровно то, что написано в файле.

Эта статья — разбор такого файла сверху вниз. Если нужно только выбрать рабочий пресет, хватит статьи [[bypass|Обход и пресеты]]; сюда стоит заглянуть, когда хочется понять, что именно делает пресет, или поправить его руками.

## Мои пресеты

Раздел «Пресеты» → «Мои пресеты» — список всех пресетов. Выбранный отмечен; чтобы сменить его, достаточно нажать на другой. Если обход включён, программа перезапустит движок с новым пресетом сама.

Встроенные пресеты приходят с программой и лежат в папке `presets\winws2_builtin`. Ваши — в `presets\winws2`, обновление их не трогает.

## Меню пресета

Правая кнопка мыши на пресете открывает меню:

- **Открыть** — посмотреть и поправить текст пресета.
- **Рейтинг** — звёздочка, чтобы помнить, какой пресет работает лучше.
- **Выше / ниже** — переставить в списке.
- **Дублировать** — копия, которую можно менять, не трогая оригинал. Самый безопасный способ экспериментировать.
- **Экспорт** — сохранить файл, например чтобы отправить коллеге.
- **Переименовать** и **Удалить** — только у ваших пресетов. Выбранный сейчас удалить нельзя.
- **Вернуть встроенный** — появляется, если встроенный пресет меняли; возвращает исходный текст.

У пресетов, добавленных по ссылке, есть ещё пункты, чтобы обновить их из источника или отвязать от него.

## Пресет это текстовый файл

Пункт «Открыть» показывает файл целиком. Править можно прямо там: изменения сохраняются сами через секунду, а если этот пресет сейчас запущен, программа сразу применяет их.

Файл читается сверху вниз и делится на две части. Сначала — общие строки, которые касаются всего пресета: подключение техник, настройки движка, какой трафик перехватывать, фейки. Потом — профили, по одному на сервис или группу сервисов.

## Служебные строки

Строки, начинающиеся с `#`, движок пропускает — для него это комментарии. Их читает сама программа: имя пресета, версия встроенного пресета (по ней программа понимает, что пришло обновление) и цвет значка в списке.

```
# Preset: Стандартный 1
# BuiltinVersion: 2.42
# IconColor: #a8c5ff
```

Трогать их не нужно. Сломать ими ничего нельзя, но и пользы от правки нет.

## Подключение техник

Строки `--lua-init` подключают файлы на языке Lua из папки `lua`. В них записаны сами техники обхода — `fake`, `multisplit` и остальные из статьи [[techniques|Приёмы обхода]].

```
--lua-init=@lua/zapret-lib.lua
--lua-init=@lua/zapret-antidpi.lua
```

Блок обязателен: без него стратегии не найдут функций, которые вызывают, и движок не запустится. Менять его не нужно.

## Общие настройки движка

Несколько строк, которые действуют на весь пресет сразу, а не на один профиль:

```
--ctrack-disable=0
--ipcache-hostname=0
```

Это внутренние настройки движка: отслеживание соединений и запоминание имён сайтов по адресам. Во встроенных пресетах они уже подобраны, менять их без понимания, зачем, не стоит.

## Какой трафик перехватывается

Строки `--wf-…` решают, какие соединения Windows вообще отдаёт движку. Перехватом занимается драйвер WinDivert.

```
--wf-tcp-out=80,443,1080,2053,8443,8080
--wf-udp-out=443-65535
--wf-raw-part=@windivert.filter/windivert_part.discord_media.txt
```

`--wf-tcp-out` и `--wf-udp-out` — исходящие порты TCP и UDP, через запятую или диапазоном. Строки `--wf-raw-part` добавляют особые случаи, которые портом не описать, — например, голосовые звонки Discord; сами правила лежат в папке `windivert.filter`.

Порта, которого здесь нет, не увидит ни один профиль ниже. Если сервис работает на нестандартном порту, начинать надо отсюда.

## Фейки

Строки `--blob` объявляют фейки — готовые поддельные пакеты из папки `bin`. Строка даёт файлу короткое имя, и стратегии зовут фейк по этому имени.

```
--blob=tls_google:@bin/tls_clienthello_www_google_com.bin
```

Здесь `tls_google` — имя, а после `@` — путь к файлу. Короткий фейк можно записать прямо байтами: `--blob=hex_00:0x00`. Фейк, которого нет в этом блоке, стратегия не найдёт: программа сама ничего не подставляет.

Сами файлы фейков двоичные: движок отправляет их в соединение байт в байт.

## Профили

После общих строк идут профили — правила вида «такой-то трафик обходить такой-то стратегией». В пресете их обычно десятки: по одному на YouTube, Discord, игры, голосовые звонки и так далее.

Каждый профиль устроен одинаково: имя, условия, к каким пакетам применять, стратегия. Профили разделяет строка `--new`. Работа с ними из интерфейса описана в статье [[profiles|Профили]].

## Имя профиля

Целиком профиль выглядит так:

```
--name=Claude
--filter-tcp=80,443
--hostlist=lists/claude.txt
--out-range=-d8
--payload=tls_client_hello
--lua-desync=multisplit:pos=1,host+2,sld+2,sld+5:seqovl=1
```

Первая строка — имя: так профиль называется в программе. Если рядом стоит строка `--skip`, профиль выключен: он остаётся в файле, но движок его пропускает. Так проще временно отключить профиль, чем удалять и потом восстанавливать.

## Когда срабатывает профиль

Условия, по которым профиль берёт соединение:

- `--filter-tcp=443` и `--filter-udp=…` — протокол и порты;
- `--hostlist=lists/youtube.txt` — список имён сайтов;
- `--ipset=lists/ipset-discord.txt` — список IP-адресов и подсетей.

Профиль срабатывает, только если подходят все условия сразу. Разница между списками имён и адресов — в статье [[profiles|Профили]].

## К каким пакетам применять

Строки, которые уточняют, какие данные и какие по счёту пакеты обрабатывать:

- `--payload=tls_client_hello` — только начало защищённого соединения, то самое место, где провайдер читает имя сайта;
- `--out-range` и `--in-range` — какие по счёту пакеты: от вас к сайту и от сайта к вам.

```
--out-range=-d8
```

Эта строка значит «только первые восемь пакетов с данными». Блокировка смотрит на начало соединения, а обработка всего остального только нагружает процессор.

Порядок важен: такие строки должны стоять перед `--lua-desync`, к которому относятся.

## Стратегия

```
--lua-desync=multisplit:pos=1,host+2,sld+2,sld+5:seqovl=1
```

Это и есть стратегия: техника (`multisplit`) и её настройки через двоеточие — здесь места, где резать пакет, и приём `seqovl`. Особый случай — `--lua-desync=pass`: «пропустить как есть». Так записан профиль, которому обход не нужен, но который должен забрать свой трафик у профилей ниже. Когда вы выбираете для профиля готовую стратегию в интерфейсе, программа меняет именно эти строки.

Строк `--lua-desync` может быть несколько — тогда техники работают вместе, например сначала фейк, потом нарезка. Что делает каждая техника — в статье [[techniques|Приёмы обхода]].

## Граница профилей

Строка `--new` закрывает профиль и начинает следующий. Так до конца файла.

Порядок профилей важен: если к соединению подходят несколько, сработает верхний. Поэтому узкие правила и исключения ставят выше общих.

## Свои пресеты

Кнопки над списком пресетов:

- **+** — создать свой пресет;
- **Импорт** — из файла или по ссылке. Пресет по ссылке может обновляться сам, когда автор его поменяет;
- **Папка пресетов** — открыть папку с файлами;
- **Вернуть встроенные** — восстановить встроенные пресеты, если их меняли.

Свой пресет удобнее всего начинать с копии встроенного: пункт «Дублировать» в меню пресета.
