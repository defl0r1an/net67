# Вики net67

Сайт документации — такой же по устройству, как тот, что вы прислали, но со своим названием, логотипом и текстом.

Тот сайт сделан сервисом Obsidian Publish за подписку. Здесь то же самое собирается генератором **Quartz**: он для того и написан, чтобы публиковать заметки Obsidian сайтом. Отсюда и знакомый вид — боковое меню, поиск, тёмная тема, ссылки вида `[[вот такие]]`, обратные ссылки и граф связей.

## Посмотреть

Двойной щелчок по **`Открыть сайт.cmd`** — откроется браузер.

Окно с сервером не закрывайте, пока смотрите: сайт живёт, пока оно открыто. Закончили — закройте окно.

> Открыть `site\index.html` файлом напрямую не выйдет. Ссылки внутри сайта ведут на `./vpn`, а не на `./vpn.html` — так устроен генератор, он рассчитан на веб-сервер. `Открыть сайт.cmd` поднимает крошечный сервер только для вашего компьютера: наружу, даже в локальную сеть, он ничего не отдаёт.

## Что где лежит

```
wiki\
  content\           статьи — их и правите
    index.md         главная
    install.md       установка
    first-run.md     первый запуск
    not-working.md   не работает
    bypass.md        обход и пресеты
    hosts.md         редактор hosts
    vpn.md           VPN по ссылке
    diagnostics.md   диагностика
    updates.md       обновления
    about.md         о программе и лицензии
    img\net67.png    логотип
  quartz.config.yaml настройки сайта: название, цвета, шрифты
  site\              собранный сайт — то, что показывает браузер
  engine\            генератор Quartz
```

## Править текст

Открывайте файлы из `content` любым редактором — это обычный markdown. Удобнее всего в Obsidian: укажите ему папку `content` как хранилище, и заработают ссылки `[[install]]`, подсказки при наборе и предпросмотр.

Ссылка на другую статью пишется по имени файла без расширения:

```markdown
[[install]]                 ссылка с заголовком статьи
[[install|Установка]]       ссылка со своим текстом
```

Цветные врезки — как в Obsidian:

```markdown
> [!tip] Заголовок врезки
> Текст.
```

Работают `note`, `tip`, `warning`, `important`, `caution`.

## Пересобрать после правок

Двойной щелчок по **`Пересобрать сайт.cmd`**.

Нужен **Node.js 22 или новее** — https://nodejs.org. Первый запуск дольше: скрипт доустанавливает зависимости генератора. Дальше сборка занимает пару секунд.

## Поменять название или цвета

Всё в `quartz.config.yaml`:

- `pageTitle` — название в шапке и в заголовке вкладки;
- `theme.colors.darkMode` и `lightMode` — палитра (сейчас графит с белым, под стать приложению);
- `theme.typography` — шрифты.

Логотип — `content\img\net67.png`, он же становится значком вкладки.

## Выложить в интернет, когда понадобится

Сейчас сайт только на вашем компьютере — так вы и просили.

Когда захотите открыть его людям, проще всего GitHub Pages: сайт статический, ему не нужен ни сервер, ни база, ни оплата. Понадобится отдельный workflow, который собирает `wiki` и публикует `site`. Скажите — сделаю.

Учтите только: репозиторий `net67` публичный, значит и сайт будет виден всем.
